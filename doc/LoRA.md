# LoRA、QLoRA、SFT 基础概念

## 1) 什么是 LoRA

**LoRA（Low-Rank Adaptation）** 是一种参数高效微调方法。  
它的核心思想是：**冻结原始大模型参数，只训练少量低秩矩阵**，把训练得到的增量能力“挂载”到模型上。

可以把它理解为：
- 原模型不大改；
- 只学一个“轻量补丁”；
- 推理时把补丁叠加到原模型能力上。

LoRA 的优点：
- 显存占用小；
- 训练速度快；
- 产物小（adapter 文件），便于多任务切换。

LoRA 的局限：
- 上限受基础模型能力影响；
- 对高质量数据依赖强；
- 任务跨度太大时，效果可能不如全参数微调。

---

## 2) 什么是 QLoRA

**QLoRA（Quantized LoRA）** 可以看作 LoRA 的“更省资源版本”。  
它通常把基础模型以 **4bit 量化**方式加载，再在其上做 LoRA 训练。

核心变化：
- 基础模型参数以低精度存储（更省显存）；
- 可训练部分仍是 LoRA adapter（参数量小）；
- 因此在较小显存 GPU 上也能微调较大模型。

QLoRA 的优点：
- 显存需求显著降低；
- 学习和实验成本更低；
- 对个人开发者/学习场景非常友好。

QLoRA 的注意点：
- 训练速度和稳定性受硬件/量化实现影响；
- 量化会带来一定精度折损（多数场景可接受）；
- 参数设置不当时更容易不稳定（如学习率过高）。

---

## 3) 什么是 SFT

**SFT（Supervised Fine-Tuning，监督微调）** 是一种训练范式：  
用“输入-输出”成对标注数据，让模型学习在给定指令下输出目标答案。

典型数据形式：
- 指令（instruction）
- 输入（input，可选）
- 参考答案（output）

SFT 解决的问题：
- 让模型更听指令；
- 让输出风格更符合预期；
- 让模型在某类任务上更稳定。

SFT 不是某个特定算法，而是“如何喂数据训练模型”的方法。  
LoRA/QLoRA 则是“以什么参数策略去微调模型”。

---

## 4) 三者关系（一句话版）

- **SFT**：训练目标和数据方式（监督学习）
- **LoRA**：参数高效的微调方法
- **QLoRA**：LoRA + 量化（更省显存）

常见组合是：**用 QLoRA 的方式做 SFT**。  
这也是当前学习大模型微调最常见、最实用的一条路线。

---

## 5) 你可以怎么选

- 设备资源充足、追求更高上限：可考虑更重的微调方式；
- 个人学习或小团队快速验证：优先 **QLoRA + SFT**；
- 要做多个垂直任务：用多个 LoRA adapter 管理不同任务能力。
